# Proyecto Sprint 7: Cuadro de Mandos de Anuncios de Vehículos

## Descripción del Proyecto
Esta es una aplicación web interactiva desarrollada con **Streamlit** y **Plotly** que permite realizar un análisis visual e interactivo sobre un conjunto de datos de anuncios de venta de coches en los Estados Unidos. Su objetivo principal es ofrecer una interfaz accesible para explorar la distribución del kilometraje y su relación con el precio de los vehículos.

## Funcionalidades
- **Histograma interactivo:** Permite visualizar de forma dinámica la distribución del kilometraje (odómetro) de los coches mediante una casilla de verificación (`st.checkbox`).
- **Gráfico de dispersión interactivo:** Permite analizar la correlación entre el precio de venta y el kilometraje de los vehículos.
- **Interfaz web responsiva:** Construida con componentes modernos de Streamlit para una experiencia fluida.
